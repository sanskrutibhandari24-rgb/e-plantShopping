
# e-plantShopping

## Paradise Nursery – Online Plant Shopping Application

e-plantShopping is an online plant shopping application where users can explore plants, browse categories, add plants to their shopping cart, update quantities, and remove items.

### Features
- Browse plants by category.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove items from the cart.
- View the total shopping cart price.
- Continue shopping or proceed to checkout.

### Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- CSS
